# FlowCourse 📅✨

> **轻量级课表显示应用 | 由 Jiaweiya 与众多 AI 共同制作**

感谢您愿意体验本应用喵~ 🎉

**FlowCourse** 是一个由 **Jiaweiya** 和一大堆 **AI** 合作开发和维护的轻量级 Android 课表显示应用。我们致力于提供简洁、美观且高效的课程管理体验，让您的学习生活更加井井有条！

---

## 🌟 主要特色

- **🎨 现代 UI 设计**：基于 **Jetpack Compose** 和 **Material Design 3** 构建，界面流畅，动画自然。
- **🤖 AI 辅助开发**：融合了人类智慧与 AI 的高效协作，持续迭代优化。
- **📱 轻量极速**：专注于核心课表功能，无多余广告和繁琐权限。
- **🔗 便捷交互**：支持点击链接跳转、富文本展示及动态资源加载。
- **🌙 主题适配**：完美跟随系统深色/浅色模式切换。

## 🛠️ 技术栈

- **语言**: Kotlin
- **UI 框架**: Jetpack Compose
- **架构**: MVVM / Compose UI State
- **依赖管理**: Gradle Kotlin DSL
